# 大黑板教学界面与自然转身

教学视图改为互不遮挡的上下两区：黑板占据对话区以上的剩余空间，底部对话区固定为约27vh（210–300px）。例题、公式与推导放在黑板，对话区保留对白、课程阶段、答题及操作。完整教材弹窗与资料库保留原内容。黑板正文按视口使用18–24px字号，长内容在板书区域内滚动，不再通过缩成小字容纳。

`web/renderer/teaching-board.js` 负责教学板书DOM，所有内容用textContent写入。`network-course.js` 把当前阶段、阶段名、选中的例题及迁移题传给板书：概念阶段显示公式与条件，推导阶段显示题目、步骤和结论，迁移阶段显示独立检验题，不提前展示解答。实体黑板也按相同阶段切换。资料库用的boardMarkup未改变。

实体黑板增大为5.8×2.55米；教室两侧外壳各向外扩大0.8米，家具保持实际尺寸，门与走廊整体平移；边界和碰撞同步。讲台增宽为8米，老师在讲台前侧左边x=-3.05至-2.05、z=-1.85的区域往返，避开门的完整开合范围。独立黑板视图使用板书层，人物不遮挡板书。

头部旋转问题修复：动画混合器采样前先恢复上一帧记录的动画基姿，采样后记录新的基姿，再处理有限追视。老师巡逻不叠加玩家追视。转身使用1.8秒，以缓入缓出的半圈旋转配合0.22倍步伐小步调整，不再停步僵硬扭转。

验证：

- `web/tests/teaching-layout.mjs`：实际高数三阶段、切换例题、黑板与对话区无交叠、桌面/手机无横向溢出。
- `web/tests/teacher-turn-browser.mjs`：实际完整转身的连续头部四元数采样；相邻采样最大变化约0.00063弧度，无累积多圈。
- `web/tests/teacher-patrol.mjs`：新路线的舞台、讲桌边界检查。
- `web/tests/paired-board-canvas.mjs`：398块实体板书绘制检查，溢出为0。
- 截图与结果：`web/.runtime/teaching-layout/desktop.png`、`mobile.png`、`verification.json`。

## 独立视角与留白修订（2026-11-03）

黑板、老师、行走均为显式视角选择。朗读不改变视角，更新课程只刷新板书内容；重新创建课堂面板时恢复现有视角和工具栏选中状态。老师谈话镜头从固定的教室前方取景，目标持续跟随老师，避免镜头随走路方向绕到门边。

黑板和对话卡片共用桌面14–48px、手机12px的外边距，中间保留12–16px间隔。正文上限24px、标题上限36px，内容仍可滚动查看。

浏览器验证老师视角在返回课堂、切换阶段和朗读启动后保持；实测门关闭、开门过渡和完全打开时，按老师0.55米包围半径计算，最近净距约0.785米。转身头部无多圈累积。桌面和手机边距、无交叠、进度更新测试均通过。

## 背景留白与完整门框修订（2026-11-04）

黑板视图的3D画布恢复覆盖整个课堂，板书浮层本身预留对话区。对话卡片与角色视图同样居中，桌面宽度min(1140px,92%)、手机94%，使用相同的半透明纸色背景及阴影。外部边距和卡片下方均直接显示教室，不再露出容器的浅绿色底色。黑板视图取景拓宽为56度。

门边问题来自旧Door_FrameL/R/Top未随替换门扇一起平移，且旧洞口右缘落在加宽阈值内。运行时移除这三个具名旧门框与旧封板，按门扇最终世界边界重建固定门框，两侧净距4.5cm；补齐旧洞口多出的墙面，添加对应碰撞。讲台门口切出凹口，补齐凹口立面，并同步可站立范围，避免门扇下部与讲台穿插。原始场景文件未改动。

验证：door-trim.mjs对开门全过程逐帧检查门扇与固定门框、墙体不相交，并验证门口讲台凹口。实际浏览器门框与黑板木框水平净距约0.5315m，无重复旧门框，四名角色正常加载；桌面和手机板书布局、课程进度更新及全屏背景覆盖通过。截图位于web/.runtime/teaching-layout和web/.runtime/classroom-style/door-repair.png、door-open-repair.png。
