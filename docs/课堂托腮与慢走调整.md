# 风堇托腮、那刻夏往返与课堂脸红关闭

风堇使用用户提供的「动作 思考托腮 by骞z魔王」VMD，按原骨架PMX名称映射，取动作完成后的姿势并烘焙成4秒保持片段，保留网页眨眼。可复现脚本：`blender/import_hyacine_thinking_pose.py`。实际资源为 `blender/animated/hyacine.blend` 和 `.glb`。

那刻夏沿用用户提供的步伐循环。`web/renderer/teacher-patrol.mjs` 将位移与步伐播放分开控制：讲桌后方z=-3.04，x从-0.75至1.45，每程7秒，端点停步并以1.5秒平滑转身；步伐速度0.55。巡逻路径使用原讲台地面高度。按身体横向半径0.28米校验，路线与讲桌及后墙均有间隔。此为课堂的固定安全路线，不是导航网格。

白厄和遐蝶的课堂脸红材质叠层「颜+」恢复隐藏，实际GLB同步设置alpha=0；网页入口也隐藏该材质，并在采样动画后将脸红/赤面/照れ/blush形态权重置零，避免下一帧恢复。原角色基础肤色贴图保留。

验证：`web/tests/teacher-patrol.mjs` 检查往返、停步、位移连续性和安全间距；`web/tests/classroom-pose-patrol.mjs` 检查实际网页移动、隐藏脸红叠层、四人加载及脚本错误，并输出 `web/.runtime/classroom-style/hyacine-thinking.png` 和 `integrity.json`。
