# 课堂与自习室人物完整性修复

课堂的三阶明暗已对齐自习室的脸部配色，去除额外UV刘海暗带；后处理目标启用最多4倍MSAA，像素比上限为2。原贴图与角色几何保留。

白厄披风并非被删除，而是成对正反衣料被导出为双面，造成共面深度争抢。四人的实际课堂GLB已按成对衣料恢复单面规则；动画、几何和内嵌贴图二进制不变。对应Blender工程同步修复；网页材质入口也保留此规则，避免再次导出双面模型后复发。透明表情层保持原显隐。

四套桌椅组件统一列坐标x=-0.5、1.2，前排z=-1.1、后排z=0.4；碰撞体继续由移动后的实际组件生成。
