# 白厄与遐蝶坐姿衣料修复

当前课堂的两套角色资源已更新：blender/build/classroom-paired/characters 下的blend、glb、fbx，网页模型缓存版本为seated-shell1。

问题包含坐姿衣料、内衬相互穿插，以及不同材质的共面叠层深度争抢。白厄内衬向内分离约10mm，外层衣料约3mm；遐蝶主要裙料与饰物分离约3–4mm，侧边蝴蝶结按原权重整体外移最多约28mm，避开座面。所有形态键同步修正一次，避免Basis重复位移。未采用会明显撑开整件裙装的骨链方案。

character-style.js为衣料、内衬和装饰建立稳定深度偏移，保留原有材质、贴图和单双面语义。原有身体动作曲线未改；GLB改按完整24秒动作区间导出，采样终点约23.958秒。

已核对两人每个材质的面数、形态键及动作曲线哈希；GLB总三角形、材质、贴图、形态键数全部保留。原文件的一份回退副本在blender/build/seated-cloth-revision/before；发布校验见publication.json和source-integrity.json。

web/tests/seated-cloth-browser.mjs通过正式接口检查四人到场、无浏览器异常，并查看两人侧面/背面以及0、6、12、18、23.95秒姿态。截图位于web/.runtime/seated-cloth/*-after*.png。该验证针对当前课堂坐姿与选定镜头，不代表完成所有可能视角的逐三角形布料碰撞证明。
