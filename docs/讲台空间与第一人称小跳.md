# 讲台空间、教学镜头与小跳

讲台地面调整为6.4×2.2米，中心(.35,-2.4)，前缘z=-1.3。学生桌凳第一排中心z=.45、第二排1.85；第一排桌前缘约.018，实际过道约1.32米。两位学生角色随桌椅同量后移，保持手和桌面关系。碰撞盒从新的桌椅网格重算；讲台可行走面同步扩大。

那刻夏移动到黑板左侧：x=-2.4至-1.7，z=-2.45。按身体半径.28米核查，在黑板左边界、讲桌及墙面之外。保持用户步伐循环与端点转身。

教师教学update与老师朗读默认使用黑板镜头：相机(.65,2.15,2.65)，看向黑板中心，36度视场，关闭景深虚化。上方新增「黑板」按钮，可切回角色或自由行走。人物交谈仍可独立选取角色视角。

自由行走时空格小跳，初速度2.5米/秒、重力9.8米/秒²，约.3米高度；落地前不能再次起跳，长按不连续跳。移动碰撞继续生效，不穿桌或门；触屏方向键旁增加「跳」按钮。走上讲台时使用新可行走面的地面高度。
